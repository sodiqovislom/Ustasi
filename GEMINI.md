# Agent Ko'rsatmalari (Ustasi loyihasi)

- **Mustaqil ishlash (Autonomy):** Barcha amallarni, kod yozish, tahrirlash va terminal buyruqlarini foydalanuvchiga ortiqcha savol bermasdan to'liq avtomatik tarzda oxirigacha yetkaz.
- **Qarorlar:** Keraksiz tasdiqlash so'rovlari o'rniga eng to'g'ri yondashuvni o'zing mustaqil tanlab, ishni bajarganingdan so'ng hisobot ber.
- **Til:** Foydalanuvchi bilan o'zbek tilida muloqot qil.
